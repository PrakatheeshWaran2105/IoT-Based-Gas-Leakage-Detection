# IoT-Based Gas Leakage Detection Using KiwisIoT

## About the Project

The **IoT-Based Gas Leakage Detection System Using KiwisIoT** is a smart safety monitoring project designed to detect gas leakage and monitor gas levels in real time.

Using a gas sensor and an ESP32/ESP8266 microcontroller, the system detects changes in gas concentration and sends sensor data to the KiwisIoT platform through Wi-Fi. Users can monitor gas readings remotely through an IoT dashboard.

This project demonstrates how IoT technology can help improve gas leakage awareness and safety monitoring in homes, laboratories, and industrial environments.
